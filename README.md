# Codex-Advanced-Hidden-Footer
Modern, responsive ve etkileşimli bir çok dilli footer/taskbar component. Proje; dil değiştirme, karanlık/aydınlık tema, arama ve kategori filtreleme, newsletter aboneliği, toast bildirimleri ve responsive tasarım özelliklerini tek bir frontend yapısında bir araya getirir.  Tamamen HTML5, CSS3 ve Vanilla JavaScript ile geliştirilmiştir.
